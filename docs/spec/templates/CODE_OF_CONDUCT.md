# Code of Conduct

We want PakkaQR to be welcoming to everyone. Be kind, be patient, assume good intent, and focus on what is best for the project and its users. Harassment, insults, discrimination and personal attacks are not tolerated.

Maintainers may remove comments, commits or contributors that break these rules. Report problems privately to: YOUR-EMAIL.

This code is adapted from the spirit of the Contributor Covenant (https://www.contributor-covenant.org).
